# 玄武攻略 WIKI

玄武江湖（2.06 / 2.13 版）的玩家攻略与资料站。纯静态手写站点：没有框架、没有构建步骤、没有外部依赖，克隆下来起个静态服务器就能跑。

整站视觉只有一句话 —— **宣纸为地，墨为字，青为脉，赭金为器，朱砂为印**。配色取自站点插画里那只龟蛇玄武，标题用中文衬线、正文用无衬线，装饰只从「印、引线、书框」这套古籍语汇里取。

## 内容

- **攻略大全** —— 全攻略总览、开局入门、前期内功推荐、武器获取、整合版
- **图鉴五类** —— 武功 361 条、内功 117 条、装备 251 条（按名称分组）、技艺、角色
- **世界地图** —— 主线任务与 7 个副本的流程节点
- **面板攻击计算器** —— 按属性推导实际面板伤害

## 技术

- 纯 HTML + CSS + 原生 JS，无打包、无 npm
- 一份 `css/wiki.css` 承载全部设计系统：`:root` 令牌 + 功能层 + 视觉世界层
- 内容数据以 JS 常量形式内联在 `js/*-data.js`，改数据即改站点
- 设计约定见 [`UI-STYLE.md`](UI-STYLE.md)，规则缘由见 [`DESIGN.md`](DESIGN.md)

## 本地运行

```bash
git clone https://github.com/charlotte114/xuanwu_wiki.git
cd xuanwu_wiki
python -m http.server 8000
# 打开 http://localhost:8000
```

> 不能直接双击 `index.html`：页面依赖相对路径与脚本加载，需要经由 HTTP。

## 目录

```
index.html            首页
pages/                栏目页与图鉴（compendium/）
articles/             长篇攻略正文
css/wiki.css          全站唯一样式表
js/                   数据与渲染脚本，按页加载
assets/images/        插画与图标
scripts/              图鉴数据的构建脚本（Python，构建时才用）
```

## 改动之前

1. 样式只往 `css/wiki.css` **末尾追加**，不要改类名 —— 协作层脚本与 18 个 jsdom 测试都按类名工作；
2. 改完要把 `?v=` 版本号升一版（静态托管不下发 `Cache-Control`，不升版本会读到旧文件）；
3. 其余细节见 `UI-STYLE.md` 的「改完必须做的三件事」。
